# V2 Momentum 策略結果

## 2026-09-10 測試

### 配置

- **策略**：Cross-sectional Momentum (12-1, long-only)
- **Universe**：120 檔（與 V1 相同，因為其他標的歷史不足）
- **Formation period**：252 天（12 個月）
- **Skip period**：21 天（排除最近 1 個月）
- **再平衡頻率**：月度（月底）
- **持倉**：Top 20%（~24 檔）
- **成本**：4bps spread + IBKR 佣金

## 關鍵發現

### ✅ 優點

1. **更高的 Risk-adjusted Return**
   - Sharpe 0.96 vs V1 的 0.82
   - CAGR 24.3% vs V1 的 ~12%

2. **低換手率**
   - 月換手僅 2%（預期 40%）
   - Momentum 訊號比預期穩定
   - 成本遠低於估計（2,400 orders/年 → 實際約 300）

3. **邏輯獨立於 V1**
   - V1 = 時間序列（波動率目標）
   - V2 = 橫截面（相對強弱）
   - 理論上相關性應該低

### ❌ 缺點

1. **回撤太大**
   - -40.4% vs V1 的 -24.6%
   - 超過 -30% 的可接受範圍
   - 典型 momentum 策略特徵（趨勢反轉時慘）

2. **波動太高**
   - 26.2% vs V1 的 ~13%
   - 雖然 Sharpe 高，但絕對波動大
   - 可能心理壓力大

3. **Universe 太小**
   - 只有 120 檔（與 V1 相同）
   - Momentum 策略理論上需要 500+ 檔才有效
   - 可能高估了真實效果

---

## 限制與警告

### ⚠️ 這個回測有問題

1. **Universe 太小**（120 檔 vs 理想 500 檔）
   - Momentum 效應在小 universe 可能被高估
   - 學術文獻的 momentum Sharpe ~0.5-0.8 是在大 universe 測的
   - 我們的 0.96 可能是 selection bias

2. **與 V1 用同樣的 120 檔**
   - 沒有真正測試「V1 + V2 diversification」
   - 因為兩者在同一個小 universe 運作
   - 相關性可能比預期高

3. **缺少 out-of-sample 驗證**
   - 這是 in-sample 回測
   - 真實表現可能差很多

## 下一步選項

### 選項 A：接受 V2 但降低配置（風險控制）

**做法**：
- V1 70% + V2 30%（保守）
- 或 V1 80% + V2 20%（非常保守）
- 降低 V2 的絕對波動和回撤影響

**前提**：
- 需要先測 V1 vs V2 的相關性
- 如果相關性 > 0.7 → 不值得
- 如果相關性 < 0.5 → 值得

### 選項 B：擴展 universe 後重測

**做法**：
- 補抓 500 檔的完整歷史（從 2016 開始）
- 重新回測 V2
- 看 Sharpe 是否還能維持 > 0.7

**工作量**：
- 需要 2-3 週補數據
- 可能發現 V2 效果大打折扣

### 選項 C：放棄 V2，專注 V1

**理由**：
- V2 的回撤太大（-40%）
- Universe 太小（可能過擬合）
- V1 已經足夠好（Sharpe 0.82）
- 不值得花時間在可能失敗的方向
